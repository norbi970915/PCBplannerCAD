# PCBPlannerCAD progress — 2026-10-27

## Routing and selection changes

Interactive Routing is the standard PCB routing tool. Press X over a pad or track, or choose Place → Interactive Routing (P T). Pad starts use the exact transformed pad center, including rotated bottom footprints. The yellow preview, green start marker and blocked-position indicator make routing state visible. Click commits the current endpoint; Escape returns to selection.

Fixed the missing-kind IPC error: Rust routing responses contain bare Track/Via structures, and the frontend now tags them as document items before committing. Raw mouse and transformed snap positions are rounded to integer nanometres before native IPC.

The router excludes ordinary copper-zone fills from collision obstacles so a different net can escape a pad through an existing pour. Committing tracks, shoved replacements and dependent copper refill is one undo step. Pads, existing routed copper, board edges and keepouts continue to constrain the router. This is covered by a route/refill/DRC/undo/redo regression. Routing previews are serialized and clicking waits for the newest endpoint. Cancelled pad/via lookups cannot restart or insert items afterward.

The right Properties / View switch remains available during selection and routing. View contains persistent type filters, All, None and Vias only. Click and box selection share the filters. Ctrl+click toggles individual items; Shift adds, Ctrl toggles and Ctrl+Shift subtracts box selections. Left-to-right boxes enclose; right-to-left boxes include touching objects.

Footprint bodies can be picked between pads and take priority over background pours. M picks up a hovered or selected footprint; R rotates, Shift+R reverses. A move and its temporary rotation commit together; Escape discards both. F or L flips a selected footprint. Connectivity-preserving footprint dragging is not yet implemented.

## Validation

- 50 editor regressions passed, covering API item tags, pad-center fanout, fractional coordinates, delayed preview commit, cancellation, filters, box direction, modifiers, footprint picks, move/rotate and cancellation.
- TypeScript validation passed.
- Production executable, MSI and NSIS installer generation passed (existing browser-externalization and chunking warnings remain).
- Rust workspace tests passed; optional performance tests remain ignored.
- Native mouse test on a disposable small board: X started at C1's signal-pad center, a visible fanout crossed the GND pour, clicking committed two tracks (23 → 25 objects), and refill cleared copper around the route. M/R showed a temporary moved/rotated footprint, and Escape restored its original position and rotation.

The native VME-WREN smoke test remained pending after the backend window title changed, with the previous board still displayed. Large-board opening/rendering is therefore unresolved; the saved fixtures are ready for further diagnosis, but responsiveness has not been validated on them.

## Continuing locally

Use pnpm.cmd dev from the repository root. To validate: pnpm.cmd -C app test:editor, pnpm.cmd typecheck, and cargo test --workspace --locked. Use pnpm.cmd build for the production executable/installers. Prerequisites are documented in README.md.
