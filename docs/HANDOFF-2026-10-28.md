# Work-laptop handoff — 2026-10-28

## Included fixes

- **WF-001:** Properties editors have distinct keys scoped to the document; stale PCB controls no longer remain beside a schematic or another selection.
- **WF-002:** Messages filters stay compact, Follow scrolls only the log, and its dock group keeps a readable minimum height on creation/restore/reopening.
- **WF-003:** schematic selection/drag hints describe the implemented controls. Space rotates and X mirrors; unsupported idle M/R actions are no longer advertised for schematics.
- **WF-004:** routed vias are validated atomically against all layers in their actual span after shove/pour planning. Rejection names the conflict/layer, preserves the route layer/anchor and leaves document/history/IDs untouched. Standalone via placement uses the same route path. Existing bad copper can still be unlocked for repair.

The native guard defaults on. The main Rules switch explicitly controls enforcement; Rules off permits violations. Loaded boards are not silently repaired. Run full DRC before accepting a layout.

## Start on the work laptop

From the existing repository checkout:

```powershell
git pull --ff-only
pnpm install --frozen-lockfile
pnpm dev
```

For the installed-style executable and installers:

```powershell
pnpm build
```

The executable is `target/release/PCBPlannerCAD.exe`. Rebuild after pulling: an older executable or a frontend-only development server does not contain the new native guard. Prerequisites are listed in [README](../README.md).
